# Настільний застосунок Windows Forms «Облік поштових відправлень» (PostService)

Настільний клієнтський застосунок на базі **Windows Forms (.NET 8.0)** для обліку та управління поштовими відправленнями через REST API серверної частини `PostService`.

---

## 📌 Основний функціонал та реалізація

### 1. Головна форма списку відправлень (`MainForm`)
- Автоматично завантажує та відображає перелік відправлень у таблиці `DataGridView` при запуску програми.
- Відображає ключові параметри: ID, вміст, відправник, одержувач, тип доставки, вага, габарити (ДxШxВ), оголошена цінність та ціна доставки.
- Панель керування містить кнопки:
  - ➕ **«Створити нове»** — відкриває діалогове вікно додавання відправлення;
  - ✏️ **«Редагувати»** — відкриває діалог для вибраного рядка таблиці (також підтримується подвійний клік по рядку);
  - 🗑️ **«Видалити»** — запитує підтвердження та видаляє вибране відправлення;
  - 🔄 **«Оновити»** — виконує повторний запит до API.
- Рядок стану (`StatusStrip`) інформує про кількість записів та поточний стан взаємодії з сервером.

### 2. Діалогове вікно створення та редагування (`PostingEditForm`)
- Єдине модальне вікно для створення нового запису та редагування існуючого.
- У режимі редагування автоматично завантажує поточні значення полів обраного відправлення.
- Кнопки **«Зберегти»** (повертає `DialogResult.OK`) та **«Скасувати»** (повертає `DialogResult.Cancel`).

### 3. Зворотний зв'язок та синхронізація
- Після закриття діалогового вікна зі збереженням головна форма миттєво відправляє запит на бекенд (POST або PUT) та оновлює таблицю `DataGridView`.

### 4. Взаємодія з REST API (`PostServiceClient`)
- Реалізовано асинхронні виклики через `HttpClient`:
  - `GET /postings` — отримання списку відправлень;
  - `POST /postings` — створення нового відправлення;
  - `PUT /postings/{id}` — оновлення даних відправлення;
  - `DELETE /postings/{id}` — видалення відправлення за ідентифікатором.
- Передбачено автоматичний демонстраційний локальний режим у разі тимчасової недоступності локального сервера `http://localhost:5000`.

### 5. Перевірка даних (Валідація)
- Реалізовано контроль правильності введених значень за допомогою `ErrorProvider`:
  - Поля «Відправник» та «Одержувач» обов'язкові (мінімум 2 символи);
  - Опис вмісту обов'язковий;
  - Вага та розміри (довжина, ширина, висота) мають бути суворо більшими за 0;
  - Вартість не може бути від'ємною.
- У разі помилок поля підсвічуються попереджувальними піктограмами з підказками.
